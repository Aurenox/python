# 💰 Rupees to English Words Converter

A simple Python program that converts a numeric rupee amount into its English word representation.

## ✨ Features

- Convert numbers into English words
- Supports values from **0 to 9,999**
- Uses the Indian numbering format (Thousand, Hundred)
- Beginner-friendly Python code
- No external libraries required

## 📌 Supported Range

| Range | Status |
|---------|---------|
| 0 - 9,999 | ✅ Supported |
| 10,000 | ⚠️ Special Case |
| Above 10,000 | ❌ Not Supported |

## 🚀 How to Run

### 1. Clone Repository

```bash
git clone https://github.com/yourusername/rupees-to-words.git
```

### 2. Move into Project Folder

```bash
cd rupees-to-words
```

### 3. Run Program

```bash
python main.py
```
